# Law v. Bentley

## Majority (Per curiam.)

Per curiam.
The facts presented by this agreed case are so confused and unsatisfactory that it is impossible to come to any conclusion entirely satisfactory to ourselves. We suppose the object of the parties is to get a construction of the release mentioned in the record. We think the release only discharged Martin for the rent which had accrued up to the time of the settlement which was made and when the release was executed.
The judgment is affirmed.
Judgment affirmed.
